# 도전과제 현지화 데이터 (KO/JA/ZH/RU) — 전체 38개

아래 표는 사람이 읽기 위한 참조본입니다. **실제 업로드는 VDF 파일로 합니다.**

## ✅ 업로드 방법 (확정 — 파일 업로드가 정답)

도전과제 현지화는 **토큰 방식**이라, 웹에서 행마다 타이핑하지 않고 **언어별 VDF 파일 하나씩 업로드**합니다.

생성된 파일 (형식은 Steam 다운로드 템플릿과 일치 검증됨):
- `assets/steam/loc/achievements_koreana.vdf`  (한국어)
- `assets/steam/loc/achievements_japanese.vdf` (일본어)
- `assets/steam/loc/achievements_schinese.vdf` (중국어 간체)
- `assets/steam/loc/achievements_russian.vdf`  (러시아어)

**절차** — 파트너 사이트 → `도전 과제 현지화`(https://partner.steamgames.com/apps/loc/4718470):
1. 언어 체크: 한국어·일본어·중국어 간체·러시아어 → **저장** *(이미 완료됨 — "Language list saved.")*
2. 하단 **현지화 키/값 파일 업로드** → `파일 선택` → 위 VDF 하나 선택 → **업로드**. (파일의 `"Language"` 키로 언어 자동 인식.) 4개 파일 각각 반복.
3. 상단 **게시(Publish)**.

> 번역 문구를 고치면 `docs/steam_achievements_localized.md`(이 파일) 수정 후
> `python3 tools/make_achievement_loc.py` 재실행 → VDF 재생성.
>
> ⚠️ 영문(English) 데이터 수정 필요: `ACH_BOSS_10` 이름 "Nightmare of Bosses **of Bosses**"(중복),
> `ACH_FLOOR_50`(Prison Break) **설명 비어있음**(플레이스홀더). 도전과제 편집기에서 English 수정 권장.
